결정: 박사님 2026-09-06 · 기준 시점 2026-09-06 · 적용 대상: 소셜앤비즈가 운영하는 모든 구글 폼과 홈페이지·브릿지·프롬프트 팩의 연락처 표시

## 1. 원칙 세 줄
1. **등록하면 반드시 두 곳에 알린다.** 등록한 사람에게는 감사 인사(화면 + 메일), 관리자(박사님)에게는 텔레그램 + 메일.
2. **받는 곳은 하나.** 알림·회신·공개 연락처는 모두 **aceyun88@gmail.com**. 옛 주소(aceyun88@naver.com)는 없애지 않고 gmail로 자동 전달해 한 수신함에서 본다.
3. **비밀값은 박사님만.** 봇 토큰·채팅 ID·스크립트 권한은 박사님 계정 안에서 넣는다. AI는 코드와 절차만 준비한다.

## 2. 폼마다 켜는 것 (체크리스트, 폼당 약 5분)
| 순서 | 설정 | 어디서 | 효과 |
|---|---|---|---|
| 1 | 확인 메시지에 감사 문구 | 설정 → 프레젠테이션 → 확인 메시지 | 제출 직후 화면 |
| 2 | 이메일 주소 수집 = 확인됨, 응답 사본 보내기 = 항상 | 설정 → 응답 | 응답자에게 구글이 사본 메일 발송(별도 이메일 문항이 있으면 지운다) |
| 3 | 새 응답에 대한 이메일 알림 받기 | 응답 탭 ⋮ | 박사님 gmail로 응답마다 메일 |
| 4 | 텔레그램 알림 + 감사 메일 | ⋮ → 스크립트 편집기에 `scripts/form-notify.gs` 붙여넣기 → 트리거 "양식 제출 시" → 스크립트 속성에 TELEGRAM_BOT_TOKEN·TELEGRAM_CHAT_ID | 텔레그램 요약 + 개인화된 감사 메일 |
| 5 | 응답 시트 연결 | 응답 탭 → 스프레드시트 아이콘 | 대장 겸 백업 |

2·4 가운데 하나만 있어도 감사 메일은 간다. 둘 다 켜면 두 통이 가니 **4를 쓰는 폼은 2의 "응답 사본"을 끈다.**

## 5. naver → gmail 자동 전달 (박사님이 한 번)
