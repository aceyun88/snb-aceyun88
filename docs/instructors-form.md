# 강사진 등록 안내 — 정보 수집 양식 · 사진 규격 · 올리는 절차

홈페이지 「강사진」 구역은 `instructors.json` 한 파일을 읽어 카드로 보여준다. 강사 한 명을 더할 때 필요한 것은 **정보 6줄과 사진 1장**뿐이며, 넷리파이 배포 없이 GitHub에 올리면 5분 안에 반영된다.

---

## 1. 강사에게 보내는 요청문 (복사해서 카카오톡·메일로)

> 안녕하세요, 소셜앤비즈 윤성임입니다. 홈페이지 강사진 소개에 올릴 정보를 부탁드립니다. 아래 6가지를 답장으로 보내 주시면 됩니다.
>
> 1. 성함
> 2. 학위 또는 대표 직함 한 가지 (예: 경영학박사 / 없으면 비워 두셔도 됩니다)
> 3. 소속과 직함 최대 3개, 현재 대표 소속부터 (예: ○○대학교 겸임교수)
> 4. 전문 분야 3~5개, 짧은 단어로 (예: 생성형 AI 실무, 데이터 분석, 소상공인 마케팅)
> 5. 소개 링크 1개 (선택 — 개인 홈페이지·블로그·프로필 주소)
> 6. 사진 1장 — **세로 방향, 얼굴이 가운데, 배경이 단순한 상반신 사진**. 휴대폰 원본 그대로 보내 주시면 제가 규격에 맞춰 잘라 씁니다. (스튜디오 사진이면 가장 좋고, 셀피도 괜찮습니다)
>
> 보내 주신 정보는 홈페이지 강사진 소개에만 쓰이며, 삭제·수정을 원하시면 언제든 말씀해 주세요.

## 2. 정보 수집 양식 (구글 폼으로 만들 때 문항 그대로)

| 번호 | 문항 | 형식 | 필수 |
|---|---|---|---|
| 1 | 성함 | 짧은 답 | 필수 |
| 2 | 학위 또는 대표 직함 | 짧은 답 | 선택 |
| 3 | 소속 1 · 직함 (현재 대표 소속) | 짧은 답 | 필수 |
| 4 | 소속 2 · 직함 | 짧은 답 | 선택 |
| 5 | 소속 3 · 직함 | 짧은 답 | 선택 |
| 6 | 전문 분야 (쉼표로 구분, 3~5개) | 짧은 답 | 필수 |
| 7 | 소개 링크 | 짧은 답(URL) | 선택 |
| 8 | 사진 | 파일 업로드(이미지, 10MB 이하) | 필수 |
| 9 | 홈페이지 게시에 동의합니다 | 체크 | 필수 |

구글 폼 설정에서 "파일 업로드"를 켜면 응답자의 사진이 내 구글 드라이브 폴더에 모인다.

## 3. 사진 규격

| 항목 | 규격 | 이유 |
|---|---|---|
| 비율 | **세로 3:4** | 카드 사진 칸이 3:4로 고정돼 있어 모든 카드가 같은 크기로 보인다 |
| 크기 | **600 × 800 픽셀** (최소 450 × 600) | 카드 폭 230px에서 고해상도 화면까지 선명하고, 파일은 가볍다 |
| 형식 | JPG, 품질 80 안팎, **300KB 이하** | 첫 화면 속도 |
| 구도 | 얼굴이 사진 위에서 30~40% 지점, 상반신, 여백 있게 | 카드에서 위쪽 30%를 기준으로 맞추므로 얼굴이 잘리지 않는다 |
| 배경 | 단색 또는 흐린 배경 | 카드가 나란히 놓였을 때 통일감 |
| 파일 이름 | `instructors/영문이름.jpg` (예: `instructors/hong-gildong.jpg`) | 한글 파일 이름은 주소 인코딩에서 깨질 수 있다 |

**강사가 규격을 못 맞춰도 된다.** 받은 원본을 아래 한 줄로 규격에 맞춘다(얼굴이 위쪽 가운데 오도록 자동으로 자른다).

```bash
python scripts/prep-photo.py 받은사진.jpg hong-gildong
```

결과는 `instructors/hong-gildong.jpg`(600×800)로 저장되고, 화면에 넣을 `photo` 값이 함께 출력된다. 규격이 어긋난 사진을 그대로 올려도 카드 안에서 자동으로 잘려 표시되지만, 얼굴 위치는 보장되지 않는다.

## 4. `instructors.json` 항목 예시

```json
{
  "name": "홍길동",
  "title": "경영학박사",
  "affiliations": [
    "○○대학교 경영학과 겸임교수",
    "△△연구소 선임연구원",
    "□□협회 자문위원"
  ],
  "fields": ["데이터 분석·시각화", "AI 업무 자동화", "소상공인 마케팅"],
  "photo": "instructors/hong-gildong.jpg",
  "link": "https://example.com/profile"
}
```

- `name` 필수. `[` 로 시작하는 항목은 견본으로 취급해 화면에 나오지 않는다.
- `affiliations`는 3개까지, `fields`는 5개까지만 표시된다.
- `photo`가 비어 있으면 이름 첫 글자를 넣은 색 상자가 대신 나온다.
- 카드 순서는 파일에 적힌 순서 그대로다.

## 5. 올리는 절차 (GitHub 웹 화면, 프로그램 설치 없이)

1. https://github.com/aceyun88/snb-aceyun88 접속 → `instructors` 폴더 열기 → **Add file → Upload files** → 규격에 맞춘 사진 끌어다 놓기 → **Commit changes**.
2. 저장소 첫 화면에서 `instructors.json` 열기 → 연필(Edit) → `items` 배열 끝의 견본 항목 앞에 4절 예시처럼 항목 추가(항목 사이 쉼표 주의) → **Commit changes**.
3. 5분 안에 홈페이지 강사진에 나타난다. 안 보이면 새로 고침(브라우저가 5분 동안 이전 파일을 기억한다).
4. 수정·삭제도 같은 방법으로 `instructors.json`만 고친다.

PC에서 작업할 때는 폴더에 사진을 넣고 `git add . && git commit -m "강사진 추가 — 홍길동" && git push`.

**주의** JSON은 따옴표·쉼표 하나가 틀리면 전체가 읽히지 않는다. 커밋 전에 https://jsonlint.com 같은 검사기에 붙여 넣어 확인하면 안전하다.
