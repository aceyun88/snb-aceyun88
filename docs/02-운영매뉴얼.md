## 2장 · 글자 고치기

`index.html`을 열고 **바꿀 글자를 그대로 검색해서** 고친다.
이게 전부다. 자주 고치는 자리만 적어둔다.

| 무엇 | 어떻게 찾나 |

| 상단 이름 | `class="logo"` |
| 큰 제목 | `<h1>` |
| 신뢰 카드 세 장 | `trust-card` |

| 주요 경력 | `주요 경력` |
| 무료 프롬프트 안내 | `id="promptpack"` |
| 출강 요청 안내 | `apply-box` |
| 연락처 | `010-2777-5004` / `aceyun88@naver.com` |

### 반드시 지킬 것

- **수치는 함부로 바꾸지 않는다.** `../CLAUDE.md`의 「호칭과 수치 표기」를 먼저 본다

### 상단 차림표에 항목 더하기

## 5장 · 문제가 생겼을 때

### 증상 · 사진이 안 보인다

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://snb-aceyun88.netlify.app/profile-yun-sung-im.jpg
```

`404`면 파일이 안 올라간 것이다. 폴더에 있는지 확인하고 다시 올린다.
파일 이름의 대소문자와 확장자까지 정확히 같아야 한다.

### 증상 · 글씨가 안 보인다

4장의 대비 검사 명령을 돌린다. 흔한 원인 둘이다.

- **밝은 바탕에 `--gold`(#c9922e)를 썼다** → `--gold-ink`(#8a6414)로 바꾼다
- **넓은 규칙이 좁은 자리까지 파고들었다** → 선택자 앞에 부모 클래스를 붙여 좁힌다

> `.cta p{color:연한색}`이 흰 상자 안 글씨까지 연하게 만든 적이 있다.
> 색을 바꾸기 전에 **어느 규칙이 이기고 있는지** 먼저 본다.

### 증상 · 고쳤는데 화면이 그대로다

브라우저 캐시다.

1. `Ctrl` + `Shift` + `R`
2. 그래도 안 되면 `127.0.0.1` ↔ `localhost`로 주소를 바꿔본다
3. 파일이 정말 바뀌었는지 확인한다 — `grep -c "찾는 낱말" index.html`

### 증상 · 문의가 안 들어온다

구글 폼에 직접 한 건 넣어 응답 시트에 들어오는지 본다.

> **이 사이트 안에 입력 폼을 다시 만들지 않는다.** 예전에 있던 폼이
> 설정값 없이 돌아가 "접수되었습니다"만 뜨고 아무 데도 도착하지 않았다.

### 증상 · 내부 문서가 인터넷에 보인다

`netlify.toml`에 그 파일 이름을 더하고 다시 올린다.
**`/*.md` 같은 꼴은 안 듣는다.** 이름을 하나씩 적거나 `docs/`에 넣는다.

## 7장 · 절대 하지 말 것

| 하지 말 것 | 무슨 일이 생기나 |
|---|---|
| 사이트 안에 입력 폼 만들기 | 문의 창구가 갈라져 하나를 놓친다 |
| 자바스크립트 넣기 | 고장 날 자리가 생긴다. 지금은 한 줄도 없다 |
| 외부 스크립트·글꼴 CDN | 남의 서비스가 죽으면 우리도 깨진다 |
| 근거 없는 수치 적기 | 담당자는 숫자가 어긋나면 나머지도 의심한다 |
| 한쪽 사이트만 고치기 | 두 사이트의 사실이 어긋난다 |
| 밝은 바탕에 `--gold` 글씨 | 흐려서 안 읽힌다. `--gold-ink`를 쓴다 |
| 확인 없이 올리기 | 4장을 거른 배포는 언젠가 사고가 된다 |

| 무엇 | 랜딩 | 프롬프트 팩 |

| 학력·경력 | 주요 경력 구획 | 소개 화면 |
