## 1. 이 사이트가 하는 일

**강의 담당자가 출강 요청서를 작성하게 하는 것.** 그것 하나다.

방문자는 대개 이런 사람이다.

- 기관·기업에서 AI 교육을 알아보라는 지시를 받았다
- 강사 이름을 듣거나 검색해서 왔다
- **다른 후보와 비교하는 중이다**
- 확인하려는 것은 셋 — 진짜 전문가인가, 우리한테 맞는 강의를 하는가, 어떻게 연락하나

그래서 화면 차례가 이렇다.

```
누구인가        (히어로 · 사진 · 신뢰 카드 세 장)
무엇을 잘하나   (전문분야)
무엇을 가르치나 (강의주제)
무료 프롬프트   (실물을 먼저 보여준다)
어떻게 하나     (교육방식)
믿을 만한가     (주요 경력 · 전문성)
신청            (출강 요청서)
```

**「무료 프롬프트」를 신청 바로 앞에 둔 이유** — 말로 하는 소개보다
직접 써볼 수 있는 물건 하나가 신뢰를 더 만든다. 66장을 훑고 온 사람은
이미 "이 강사는 실물이 있다"고 판단한 상태다.

## 2. 하지 않기로 한 것

| 하지 않는 것 | 이유 |
|---|---|
| 사이트 안 입력 폼 | 문의 창구를 구글 폼 하나로 모았다. 둘이면 하나를 놓친다 |
| 자바스크립트 | 지금 한 줄도 없다. 없으면 고장 날 것도 없다 |
| 외부 글꼴 CDN | 남의 서비스가 죽으면 글꼴이 깨진다. 시스템 글꼴로 충분하다 |
| 후기·추천사 | 검증 없는 후기는 오히려 신뢰를 깎는다 |
| 근거 없는 숫자 | 「수치 표기」 규칙을 볼 것 |
| 블로그·소식 | 관리 못 하면 낡은 글이 남는다. 낡은 소식은 안 하느니만 못하다 |

## 3. 수치를 함부로 쓰지 않는 이유

예전에 「약 800회 누적 출강」, 「저서 36권+」이 적혀 있었다.
**근거를 확인할 수 없는 값이었고, 대표 프로필과도 어긋났다.**

강의 섭외 담당자는 숫자를 본다. 그리고 그 숫자가 다른 자료와 다르면
**그 순간 나머지 전부를 의심한다.** 부풀린 숫자 하나가 진짜 실적까지 깎는다.

그래서 확인된 값만 쓴다.

| 쓴다 | 안 쓴다 |
|---|---|
| 기술창업학 박사 · 겸임교수 | 누적 출강 횟수 |
| KT·KTDS 약 16년 | 저서 36권 / 51종 |
| 저서·공저 50여 종 | "약 30년 디지털 현장" |

기준 문서는 「윤성임 브랜딩 대표프로필」 2026.08판이다.
**프롬프트 팩 사이트와 반드시 같은 값을 쓴다.** 두 사이트가 서로 링크로
이어져 있어 오가는 사람이 다른 숫자를 보면 안 된다.

## 4. 두 사이트의 관계

```
강사 랜딩 (snb-aceyun88)          프롬프트 팩 (snb-prompt-pack)
  신뢰를 만든다                     쓸모를 겪게 한다
  강의를 판다                       무료로 준다
  둥글고 부드러운 모양              각지고 서식 같은 모양
  "프롬프트"라고 부른다              "지시서"라고 부른다

  [무료 프롬프트]  ──────────▶  첫 화면
       ◀──────────  [강사 홈페이지 · 강의 주제 보기]

           둘 다 → 구글 폼 「출강 요청 접수」
```

**색과 낱말이 다른 것은 실수가 아니라 의도다.** 두 사이트는 역할이 다르다.
다만 **사람에 관한 사실(호칭·학력·경력·수치)은 반드시 같아야 한다.**

## 5. 화면 구조

한 장짜리 HTML이다. 구획 여섯 개와 상단 차림표, 발밑으로 되어 있다.

| 구획 id | 무엇 |
|---|---|
| (히어로) | 이름·한 줄 소개·신뢰 카드 세 장·프로필 사진 |
| `#expertise` | 전문분야 |
| `#courses` | 강의주제 |
| `#process` | 교육방식 |
| (경력) | 주요 경력 · 주요 전문성 |
| `#promptpack` | 무료 프롬프트 안내 → 팩 사이트로 |
| `#apply` | 출강 요청서 안내 → 구글 폼으로 |

상단 차림표 — 전문분야 · 강의주제 · **무료 프롬프트** · 교육방식 · 강의신청
