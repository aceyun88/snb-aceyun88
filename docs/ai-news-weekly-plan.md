# AI 소식 주간 정리 — A안(API 없이) 계획 (2026-09-04, 박사님 승인)

## 목표
매주 월요일 한 게시글에 "이번 주 핵심 주제 10개 안팎"을 보여 준다. 주제마다 출처 링크를 붙이고, 요약 문장은 지어내지 않고 **출처가 써 둔 글**만 옮긴다. 수집 범위는 생성형 AI 활용 정보로 좁힌다. GitHub 저장소는 "무엇에 쓰는 도구인지"를 앞세운다.

## 방법
| 항목 | 방법 | 비용 |
|---|---|---|
| 범위 | 제목·설명이 생성형 AI 활용 낱말(챗GPT·클로드·제미나이·프롬프트·에이전트·바이브 코딩·이미지/영상 생성 등)에 걸리고, 제외 낱말(국방·군사·주가·소송·반도체·데이터센터·채용 등)에 걸리지 않는 것만 | 0 |
| 주제 묶기 | 낱말 표로 13개 주제(챗GPT·OpenAI / 클로드·앤트로픽 / 제미나이·구글 / 코파일럿·MS / AI 검색 / 이미지·영상 생성 / 에이전트·자동화 / 바이브 코딩·개발 도구 / 오픈소스 모델·도구 / 국내 AI / 교육·학습 / 업무 활용·생산성 / 그 밖의 소식)에 배정, 항목 수·점수 순으로 최대 10개 주제 표시 | 0 |
| 요약 문장 | 긱뉴스 글 본문 첫 220자(한국어 요약) · AI타임스 기사 og:description · 구글 뉴스는 제목만 · 조코딩은 방송 제목의 항목 목록 | 0 |
| GitHub 설명 | GitHub API의 저장소 설명(영문)을 DeepL 무료 API(키 있을 때) 또는 MyMemory 무료 번역(키 없을 때)으로 한국어화, 영문 원문도 함께 | 0 |
| 화면 | 최신 주가 펼쳐진 채로, 주제 카드(주제명 → 대표 소식 제목·요약 → 출처 목록). 옛 형식 게시글은 출처별 목록으로 그대로 표시 | 0 |

## 한계와 다음 단계
- "새로 쓰는 요약"이 아니라 "출처의 요약을 모아 정리"다. 문장이 하나로 합쳐지지 않는다.
- 기계 번역이라 GitHub 설명이 어색할 수 있어 영문 원문을 같이 둔다. DeepL 키(월 50만 자 무료)를 넣으면 품질이 오른다.
- 요약 품질이 아쉬우면 B안(구독 예약 실행 또는 Gemini 무료 등급)을 얹는다. A안의 수집·묶기·출처 구조는 그대로 쓴다.

## 검증
- `python scripts/fetch-ai-news.py` 실행 → ai-news.json에 `topics`가 생기고 주제마다 `items`와 출처가 있다.
- 미리보기 배포에서 최신 주 카드가 주제별로 보이고, 지난 주(옛 형식)도 깨지지 않는다.
